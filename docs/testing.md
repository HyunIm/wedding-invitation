# 개발과 확인 기록

## 자동 검사

Node.js 24 LTS의 24.15 이상과 Python 3.12를 사용합니다. 지원 Node 버전은 package.json에도 명시되어 있습니다. jsdom은 테스트 전용이며 배포 페이지에는 포함하지 않습니다.

```
npm ci
npm test
node scripts/ai-pack.mjs --check
node scripts/build.mjs --demo
python3 -m pip install -r scripts/requirements.txt
python3 -m unittest discover -s tests -p 'test_*.py'
python3 scripts/optimize_images.py _site
python3 -m http.server --bind 127.0.0.1 -d _site 8000
```

일반 사용자 빌드는 `node scripts/build.mjs`입니다. 빈 시작 설정은 의도적으로 실패합니다. 테스트는 임시 폴더에서 사용자 설정을 채운 빌드와 오류 시 기존 출력 보존을 확인합니다. 원본 저장소의 데모는 --demo로만 만들며 새 사용자에게 자동 적용되지 않습니다.

PR에서는 테스트·안내문 동기화·데모 빌드·사진 검사를 실행합니다. main 배포에서도 동일 검사 후 실제 사용할 설정으로 빌드합니다. 원격 Google/Kakao 서비스, 운영체제의 캘린더 처리, 실제 사용자 완주 여부는 모의 실행으로 보장할 수 없습니다.

## 비전공자 사용성 확인

테스트용 가상 이름·예식 정보·공개 가능한 사진으로 진행하세요. 새 ChatGPT 대화에서 README의 요청 문장을 보내고, 개발자가 직접 조작하지 않은 상태로 다음을 확인합니다.

1. 안내문/설정을 실제로 읽었는지, 읽지 못했을 때 단일 안내문으로 복구하는지
2. 공개 범위를 이해하고 사진 사본을 준비하는지 (HEIC도 한 번 시도)
3. 저장소 생성 → 설정 → 업로드 → Pages → 배포까지 완료하는지
4. 날짜 변경 후 본문·캘린더·공유 미리보기가 함께 바뀌는지
5. 잘못된 시간/표지 누락 오류를 보고 AI와 복구할 수 있는지

소요 시간, 막힌 단계, AI가 잘못 안내한 내용, 사람의 도움이 필요했던 횟수를 기록하세요. 자동 테스트는 이 사용성 확인을 대신하지 않습니다.
