# 📸 사진 · 음악

모든 사진은 **`images` 폴더**에 올려요.
`https://github.com/내아이디/저장소이름/upload/main/images` 를 열고 끌어다 놓은 뒤 **`Commit changes`** 를 누르면 끝이에요.

| 파일 | 용도 | |
|---|---|---|
| `images/cover.jpg` | 표지 (세로 사진) | 필수 |
| `images/og.jpg` | 카톡·문자 공유 미리보기 (가로 사진, 1200×630 이 가장 예뻐요) | 없으면 표지 사용 |
| `images/closing.jpg` | 맨 마지막 사진 | 선택 |
| `images/gallery/` 폴더 | 갤러리 — **올린 사진이 전부 자동으로 나와요** | |
| `images/bgm.mp3` | 배경음악 | 선택 |

## 갤러리
- `https://github.com/내아이디/저장소이름/upload/main/images/gallery` 에 여러 장을 한꺼번에 끌어다 놓으세요.
- **순서 = 파일 이름 순서**예요. 원하는 순서가 있으면 `01.jpg`, `02.jpg` … 로 이름을 바꿔서 올리세요.
- 빼고 싶은 사진은 그 파일을 열고 오른쪽 위 `···` → `Delete file`.

## 사진 크기는 신경 쓰지 않아도 돼요
배포할 때 자동으로
- 긴 변 1600px 로 줄이고 (한 장 5~10MB → 200~400KB)
- 갤러리용 작은 미리보기를 따로 만들고
- 사진 속 위치정보(GPS)·촬영기기 정보를 지워요.

저장소에 올린 원본은 그대로 남아요. 단, GitHub 웹에서는 **파일 하나당 25MB** 까지만 올릴 수 있어요.

## ⚠️ 주의
- **아이폰 HEIC 사진은 안 돼요.** 휴대폰 웹에서 올리면 보통 자동으로 JPG 로 바뀌어요.
  컴퓨터에서 올릴 땐 JPG 로 내보내거나, 아이폰 `설정 → 카메라 → 포맷 → 높은 호환성` 으로 찍어주세요.
- 파일 이름의 대소문자·확장자는 달라도 괜찮아요. (`Cover.JPG`, `cover.jpeg` 도 표지로 인식)

## 🎵 배경음악
1. `images` 폴더에 mp3 파일을 **`bgm.mp3`** 이름으로 올리세요. (5MB 이하 권장)
2. config.js 에서 `music` 의 `enabled: true` 로 바꾸세요.
3. 휴대폰 정책상 하객이 **화면을 한 번 터치해야** 음악이 시작돼요. 오른쪽 위 🎵 버튼으로 끌 수 있어요.

> 저작권이 있는 음악은 문제가 될 수 있어요. 무료 음원(예: YouTube 오디오 보관함)을 추천해요.

## 🗺️ 약도 이미지
지도 대신 예식장 약도를 쓰려면 `images/map.jpg` 로 올리고 config.js 의 `location.mapImage: 'images/map.jpg'` 로 적으세요.
