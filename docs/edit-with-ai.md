# 🤖 AI 로 청첩장 고치기

처음 만들 때는 [README](../README.md) 의 한 줄이면 충분해요.
이 문서는 **다 만든 뒤에 내용이나 디자인을 바꾸고 싶을 때** 쓰는 방법이에요.

## 고치는 방법

1. `https://github.com/내아이디/저장소이름/edit/main/config.js` 를 열고 안의 글을 **전부 복사**합니다.
2. AI 에게 아래 질문 중 하나와 함께 붙여넣어 보냅니다.
3. AI 가 준 **전체 내용**을 같은 화면에 (기존 글을 전부 지우고) 붙여넣고 **`Commit changes`**.
4. 1~2분 뒤 청첩장을 새로고침하세요.

> ⚠️ Actions 탭에 빨간 ❌ 가 생기면 AI 가 쉼표 등을 빠뜨린 거예요. 기존 청첩장은 그대로 안전해요.
> ❌ 를 눌러 나온 빨간 글을 복사해서 "이 오류 고쳐줘" 라고 보내세요.

## 📋 복붙용 질문

**내용 바꾸기**
```
아래 config.js 에서 [바꿀 내용]만 바꿔서 전체 파일을 코드 블록 하나로 출력해줘.
구조·주석·따옴표·쉼표는 그대로 두고, 말하지 않은 항목은 바꾸지 마.

[config.js 붙여넣기]
```

**디자인 바꾸기**
```
아래 config.js 에서 색상은 sage, 글꼴은 hand, 표지는 arch, 효과는 snow, 갤러리는 slide 로 바꿔서
전체 파일을 출력해줘.

[config.js 붙여넣기]
```

**섹션 순서 바꾸기 / 숨기기**
```
아래 config.js 에서 '영상' 은 숨기고, '마음 전하실 곳' 을 '오시는 길' 바로 다음으로 옮겨서
전체 파일을 출력해줘.

[config.js 붙여넣기]
```

**인사말 써달라고 하기**
```
모바일 청첩장 인사말을 3가지 버전으로 써줘. 8줄 이내, 따뜻하고 담백하게.
우리는 [만난 계기 / 연애 기간 등] 이야.
```

**오류 고치기**
```
config.js 를 고쳤더니 아래 오류가 났어. 고친 전체 파일을 출력해줘.

오류: [빨간 글 붙여넣기]

[config.js 붙여넣기]
```
