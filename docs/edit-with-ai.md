# AI로 기존 청첩장 고치기

1. 내 저장소의 **현재 config.js 전체**를 복사하거나 파일로 내려받으세요.
2. AI에게 바꿀 내용과 함께 전달하세요. 새 사용자용 기본 설정으로 덮어쓰지 마세요.
3. 수정한 전체 파일을 내 저장소의 config.js에 넣고 Commit changes를 누르세요.
4. 이번 Actions 실행 결과를 확인한 뒤 실제 청첩장과 카톡 미리보기를 확인하세요.

```
첨부한 현재 config.js에서 [바꿀 내용]만 수정해줘.
다른 정보와 키·주석은 유지해줘. 전체 config.js를 내려받을 파일로 제공하고,
파일 제공이 안 되면 생략 없이 코드 블록 하나로 출력해줘.
이름·날짜를 바꿀 때 공유 제목과 설명도 확인해줘.
```

`meta.title`, `meta.description`, `firstName`을 비워두면 이름·예식 정보에서 자동으로 표시합니다. 별도 문구를 직접 넣었다면 내용 변경 시 함께 확인하세요. 계좌 예금주가 신랑·신부 이름과 다르면 계좌의 `name`을 직접 지정하세요.

코드가 중간에 끊기면 조각을 이어붙이지 말고 **완성된 파일 전체**를 다시 요청하세요. 긴 코드 붙여넣기가 어렵다면 다운로드 파일을 사용하세요. 오류는 [실패 단계별 안내](troubleshooting.md)를 참고하세요.

사진 업로드를 AI가 대신할 수 있는지는 연결된 도구와 권한에 따라 다릅니다. 직접 할 때는 [사진 안내](photos.md)를 따르세요. 어떤 방법이든 공개하지 않을 정보를 원본 파일에서 지우고 정리한 사진 사본만 올리세요.
