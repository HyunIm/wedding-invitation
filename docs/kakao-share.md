# 💬 카카오톡 공유 설정

## 링크만 보내도 미리보기는 나와요
청첩장 주소를 카톡에 붙여넣으면 config.js 의 `meta` (제목·설명·사진) 로 미리보기가 만들어져요.
**카카오톡 공유 버튼**(예쁜 카드 + "청첩장 보기"/"위치 보기" 버튼)을 쓰고 싶을 때만 아래를 따라 하세요.

## 1. 카카오 개발자 앱 만들기
1. https://developers.kakao.com 접속 → 카카오 계정으로 로그인
2. **`내 애플리케이션` → `애플리케이션 추가하기`**
   - 앱 이름: `우리 청첩장` (아무거나) / 회사명: 본인 이름
3. 만든 앱을 클릭

## 2. 내 청첩장 주소 등록
1. 왼쪽 **`앱 설정` → `플랫폼`** (또는 `앱 키` 화면의 JavaScript 키 설정)
2. **`Web 플랫폼 등록`** → 사이트 도메인에 입력:
   ```
   https://내아이디.github.io
   ```
   (뒤에 저장소 이름은 빼고, 끝에 `/` 없이)
3. 저장

## 3. JavaScript 키 복사
**`앱 설정` → `앱 키`** 에서 **JavaScript 키** 를 복사해 config.js 에 넣어주세요.
```js
share: {
  kakaoJsKey: '여기에-JavaScript-키',
  kakaoButtonText: '청첩장 보기',
},
```
> JavaScript 키는 원래 웹페이지에 공개되는 키라서 올려도 괜찮아요. (등록한 도메인에서만 동작해요)

## 4. 카톡 미리보기가 예전 사진으로 나올 때
카카오톡은 미리보기를 한동안 저장(캐시)해 둬요.
https://developers.kakao.com/tool/debugger/sharing 에서 청첩장 주소를 넣고 **`캐시 초기화`** 를 눌러주세요.
