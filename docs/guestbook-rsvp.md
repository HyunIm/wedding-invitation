# 📝 방명록 · 참석여부를 구글 시트로 받기

방명록과 참석 의사(RSVP) 응답이 **내 구글 시트에 자동으로 쌓여요.** 무료이고 5분이면 됩니다.
(설정하기 전에는 이 두 섹션이 손님에게 자동으로 숨겨져요.)

## 1. 구글 시트 만들기
1. https://sheets.new 접속 (구글 로그인) → 새 시트가 열려요.
2. 왼쪽 위 제목을 `청첩장 응답` 처럼 바꿔주세요.

## 2. 코드 붙여넣기
1. 메뉴 **`확장 프로그램` → `Apps Script`** 클릭
2. 왼쪽 `Code.gs` 안의 글을 **전부 지우고**
3. 이 저장소의 [`google-apps-script/Code.gs`](../google-apps-script/Code.gs) 내용을 **통째로 복사해서 붙여넣기**
4. 💾 저장 아이콘 클릭

## 3. 웹 앱으로 배포
1. 오른쪽 위 파란 **`배포` → `새 배포`**
2. 톱니바퀴 ⚙️ → **`웹 앱`** 선택
3. 설정:
   - **다음 사용자 인증 정보로 실행:** `나`
   - **액세스 권한이 있는 사용자:** `모든 사용자` ← 꼭!
4. **`배포`** → **`액세스 승인`** → 내 구글 계정 선택
   - "Google에서 확인하지 않은 앱" 경고가 나오면 **`고급` → `(안전하지 않음)으로 이동`** → **`허용`**
   - (내가 만든 코드라서 나오는 경고예요. 이 코드는 내 시트에만 글을 쓸 수 있어요.)
5. 나온 **웹 앱 URL** 을 복사 (`https://script.google.com/macros/s/.../exec`)

## 4. config.js 에 붙여넣기
```js
googleScriptUrl: 'https://script.google.com/macros/s/여기에-복사한-주소/exec',
```
저장(Commit) 후 1~2분 뒤 청첩장에서 방명록과 참석 여부 버튼이 나타나요.

## ✅ 확인하기
- 복사한 URL 을 브라우저에 그냥 열었을 때 `"청첩장 서버가 정상 동작 중입니다."` 가 보이면 성공!
- 청첩장에서 방명록을 하나 남겨보면 시트에 **`방명록`** 탭이 생기고 글이 들어와요.
- 참석 여부는 **`참석여부`** 탭에 쌓여요. 시트의 필터 기능으로 신랑측/신부측, 식사 인원을 셀 수 있어요.

## 🙈 방명록 글 숨기기
부적절한 글이 있으면 시트의 그 줄 **`숨김`** 칸에 `TRUE` 라고 적으면 청첩장에서 사라져요. (행을 삭제해도 돼요)

## ❓ 코드를 수정한 뒤에는
Apps Script 코드를 바꿨다면 **`배포` → `배포 관리` → ✏️ → 버전: `새 버전` → `배포`** 를 해야 반영돼요.
(이렇게 하면 URL 은 그대로 유지돼요.)
