# 기존 청첩장 업데이트

이미 사용 중인 config.js를 새 빈 설정으로 덮어쓰지 마세요. 먼저 기존 설정을 보관하세요.

1. 공개 범위를 확인하고 최상위에 `privacy: { publishConsent: true },`를 추가합니다. 공개하지 않을 값은 숨기기만 하지 말고 파일에서 지우세요. 이전 Git 기록은 별도 관리가 필요합니다.
2. `meta.title`, `meta.description`, `firstName`은 자동값을 원할 때 빈 문자열로 바꿉니다. 특별히 지정한 문구는 유지해도 되지만 예식 정보 변경 시 함께 확인하세요.
3. 실제 없는 날짜·시간, 비어 있는 이름/장소/주소, 누락된 표지 사진, 따옴표로 감싼 불리언, 알 수 없는 키 등은 이제 배포 오류입니다. 오류에 표시된 항목을 고치세요. 예시 계좌는 삭제하세요.
4. `index.html`, `templates/`, `assets/`, `scripts/`, 워크플로와 도구 페이지를 함께 업데이트하세요. 최신 app.js는 config-utils.js를 먼저 읽어야 합니다.
5. 구글 시트를 사용한다면 Code.gs도 갱신하고 Apps Script의 새 버전을 배포하세요. 구버전 서버와의 조회 호환은 제공하지만 새 인원 검사·중복 제한은 새 서버 코드가 필요합니다.
6. 사진은 앞으로 prepare.html에서 만든 사본을 사용하세요. 이번 업데이트가 기존 저장소의 원본이나 Git 이력을 지우지는 않습니다.

원본 저장소만 데모 전용 빌드를 선택합니다. 템플릿에서 만든 저장소는 config.js와 images만 사용하며 demo 폴더 유무와 관계없이 사용자 설정으로 배포합니다.
