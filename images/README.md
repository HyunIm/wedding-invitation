# 내 사진 올리는 곳

**공개할 사진 사본만** 올리세요. 먼저 [사진 준비 도구](https://hyunim.github.io/wedding-invitation/prepare.html)에서 JPG로 만들고 위치·기기 정보를 제거하세요. 배포 때의 최적화는 저장소 원본과 Git 기록을 바꾸지 않습니다.

표지 cover.jpg는 필수입니다. 공유용 og.jpg, 마무리 closing.jpg, 음악 bgm.mp3는 선택입니다. 갤러리 사진은 gallery/ 안에 넣으세요. ZIP은 압축을 풀어 사진 파일만 업로드합니다.

HEIC/HEIF는 사진 앱에서 JPG로 내보내세요. 확장자만 변경하면 안 됩니다. `Add file → Upload files`에서 사본을 선택한 뒤 Commit changes를 누르세요. 자세한 내용은 [사진 안내](../docs/photos.md)를 참고하세요.
