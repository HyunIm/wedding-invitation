# 📷 내 사진 올리는 곳

이 화면 오른쪽 위 **`Add file` → `Upload files`** 로 사진을 끌어다 놓고 **`Commit changes`** 를 누르세요.

| 파일 이름 | 용도 | |
|---|---|---|
| `cover.jpg` | 표지 사진 (세로 사진) | 필수 |
| `og.jpg` | 카톡·문자 공유 미리보기 (가로 사진) | 없으면 표지 사진 사용 |
| `closing.jpg` | 맨 마지막 사진 | 선택 |
| `bgm.mp3` | 배경음악 | 선택 |
| `gallery/` 폴더 | 갤러리 사진 — **올리기만 하면 자동으로 전부 나와요** | |

- 휴대폰 원본 사진을 그대로 올려도 괜찮아요. 배포할 때 자동으로 가볍게 줄이고 위치정보(GPS)를 지워요.
- `.jpg` `.jpeg` `.png` 모두 돼요. 아이폰 `HEIC` 는 안 돼요. (설정 → 카메라 → 포맷 → 높은 호환성)
- 갤러리 순서는 파일 이름 순서예요. 원하는 순서가 있으면 `01.jpg`, `02.jpg` … 로 이름을 바꿔 올리세요.
